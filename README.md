# 电池功率组件 BatteryGlance

一款简洁的 Windows 电池状态桌面组件，随时看一眼电量、充放电功率和剩余时间。

## 功能

- 显示电量和电池充放电功率
- 显示剩余续航或预计充满时间
- 自定义显示内容、大小和位置
- 系统托盘菜单和诊断日志导出

## 下载使用

1. 进入本项目的 Releases。
2. 下载 Assets 中的 BatteryGlance-v0.5.2.zip。
3. 解压到一个文件夹。
4. 双击 BatteryGlance.exe 运行。

## 使用说明

- 在设置页面启用桌面组件。
- 双击组件进入位置调整模式，拖动后再次双击确认。
- 通过系统托盘菜单打开设置或退出程序。

## 数据说明

- 功率表示电池净充放电功率，不代表充电器输入功率或整机功耗。
- 数据是否可读取，取决于电脑硬件和系统支持。
- 无法读取的数据会显示为未知或占位符。
- 预计充满时间带有 ≈ 时，表示根据当前充电速率估算，实际时间可能变化。
